# Ohm's Law Calculator ⚡

A beginner-friendly Python calculator for calculating Voltage, Current, and Resistance using Ohm's Law.

## 📐 Formula

Ohm's Law:

V = I × R

Where:
- V = Voltage (Volts)
- I = Current (Amperes)
- R = Resistance (Ohms)

## 🚀 Features

- Calculate Voltage
- Calculate Current
- Calculate Resistance
- Simple command-line interface
- Beginner-friendly Python project

## 🛠️ Technology Used

- Python

## 🎓 Purpose

This project was created as part of my Electrical and Electronics Engineering learning journey to practice Python programming and apply basic electrical circuit concepts.

## ▶️ How to Use

Run the `ohms_law.py` program and choose whether you want to calculate Voltage (V), Current (I), or Resistance (R). Then enter the required values.
